# Paper — CAEPIA Doctoral Consortium submission

LNCS version of ARGUS, written for the CAEPIA Doctoral Consortium. Superseded by
the ClimateNLP 2026 paper in `../paper_climatenlp/`, which is the version to read;
this draft is kept for the record and its numbers predate the camera-ready
corpus fix (it still reports 27 papers rather than 26).

## Layout

- `main.tex` — entry point (title, abstract, `\input`s the sections)
- `sections/` — introduction, related_work, framework, evaluation, results,
  discussion, conclusion
- `references.bib` — bibliography for this draft
- `figures/figure1.pdf` — current Figure 1 (from `../ARGUS Figure1.pdf`)
- `research_questions.md`, `contributions.md` — planning notes feeding the prose

## Build dependencies (not bundled)

Needs Springer's `llncs.cls` and `splncs04.bst` in this folder or your TeX
distribution. Then:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Numbers in `sections/results.tex` are regenerated by
`PYTHONPATH=src python3 experiments/phase1_pilot/run_baseline_eval.py`.

> Build with `tectonic main.tex` if Springer's class files are present.
