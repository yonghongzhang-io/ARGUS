\begin{abstract}
Empirical economics leans heavily on difference-in-differences (DID) designs,
whose credibility rests on identification assumptions that are often asserted
rather than audited. We present \textbf{ARGUS}, a responsible-AI framework that
audits the \emph{identification credibility} of such studies---whether their
reported evidence adequately supports each identification assumption---instead of
adjudicating the true causal effect, which is never observed. ARGUS decomposes
identification into auditable dimensions, gathers in-paper evidence, assesses each
assumption--implication--evidence chain, and localizes risk in a transparent,
human-reviewable report. We validate the auditor with synthetic flaw injection,
which supplies reproducible local ground truth without the true effect: a
deterministic keyword baseline detects only $0.182$ of injected flaws because it
cannot see flawed-but-present evidence, whereas judging evidence \emph{adequacy}
catches the flaws keyword presence misses ($1.000$ detection, no false alarms).
Presence, in other words, is not adequacy. On 27 real DID papers the binding
constraint shifts to evidence grounding rather than over-flagging. A pilot
human-gold study then exposes a systematic over-severity bias that a lightweight,
anchor-based calibration layer reduces while preserving high-risk recall. ARGUS is
thus a high-sensitivity screening tool that flags dimensions for expert review
rather than issuing verdicts; the human-gold study is pilot-scale.
\keywords{Responsible AI \and Causal inference \and Difference-in-differences
\and Environmental policy \and LLM agents.}
\end{abstract}
