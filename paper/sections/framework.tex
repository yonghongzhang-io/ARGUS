\section{The ARGUS Framework}
\label{sec:framework}

\subsection{Identification rubric}
ARGUS decomposes a DID study into eleven auditable dimensions: parallel trends,
no anticipation, staggered-timing handling, SUTVA/spillovers, control-group
construction, specification, inference, sample-period selection, concurrent
policies, placebo/robustness, and data measurement. Each dimension is expressed
as an \emph{assumption} (what must hold for identification), a testable
\emph{implication} (what should therefore be observable), and the
\emph{evidence} a credible paper would report to support it---for example, the
parallel-trends dimension expects an event-study or pre-trend test with null
pre-period coefficients. The rubric is declarative, stored in a configuration
file (\texttt{identification\_dimensions.yaml}), so that the set of audited
dimensions is explicit and inspectable rather than buried in code. A companion
flaw taxonomy (\S\ref{sec:evaluation}) maps each known identification threat
one-to-one onto a dimension, which both documents the rubric's coverage and
supplies the perturbations used for evaluation.

\subsection{Bounded-agentic pipeline}
The audit runs a fixed, deterministic sequence---\emph{decomposition
$\rightarrow$ extraction $\rightarrow$ assessment $\rightarrow$ localization
$\rightarrow$ report}---shown in the top band of Figure~\ref{fig:arch}. The stage
order is written in code and is never chosen by a model. \emph{Decomposition}
instantiates the rubric for the paper at hand. \emph{Extraction} gathers, per
dimension, the in-paper evidence relevant to that assumption. \emph{Assessment}
evaluates each assumption--implication--evidence chain and emits a per-dimension
risk judgement with a rationale and cited evidence. \emph{Localization}
aggregates these judgements into a risk map that ranks where support is weakest.
\emph{Report} renders a transparent, evidence-anchored document for a human
reviewer.

Agency is confined to the two stages where open-ended judgement actually helps,
extraction and assessment. Each invokes a bounded ReAct-style loop with three
constraints: (i)~a \emph{small fixed tool set} passed in per call---%
\texttt{evidence\_search} over the paper's text, figures and tables,
\texttt{figure\_parse} for structured figure/table content, and
\texttt{policy\_lookup} for policy metadata such as announcement versus
implementation dates; (ii)~a \emph{hard step budget} (\texttt{max\_steps}) so a
run cannot wander indefinitely; and (iii)~a \emph{logged trace} of every step,
tool call, and cited piece of evidence. All other stages are plain orchestration
with no agent loop.

\paragraph{Why bound the agency.}
A fully autonomous agent would make per-run behaviour path-dependent and
high-variance, which would undermine the central evaluation claim of
\S\ref{sec:evaluation}---that flaw injection provides \emph{reproducible} local
ground truth. Restricting agency to two clearly scoped sub-tasks preserves
reproducibility (stable, comparable metrics) and evidence-traceability (every
judgement anchored to logged evidence a human can inspect). The expert sits at
the end of the pipeline: ARGUS surfaces and localizes identification risk, it
does not adjudicate it.

\subsection{Output}
ARGUS emits \emph{(study, identification dimension, risk)} triplets, each with an
evidence-grounded rationale, together with the human-readable report. It never
produces a verdict on the true causal effect. This output shape is what makes
the system both auditable by a human and measurable by the evaluation that
follows.
